## 찍을 때 주의

- 버튼을 누른 뒤 초록 안내 문구가 뜰 때까지 1~2초 기다렸다 다음으로 넘어가면 결과가 화면에 남습니다.
- Claude로 찍었는데 첫 질문에서 AI가 광고를 추천하지 않으면 숫자가 달라집니다. 다시 찍거나 `AI_PROVIDER=rule`로 촬영하세요.
- 다시 찍을 때는 `npm run demo:reset` → 브라우저 새로고침 (서버는 켠 채로).
- 화면에 개인 정보(다른 탭, 메신저 알림, 실제 지갑 주소)가 나오지 않게 합니다. 시연 지갑 주소는 공개 테스트 계정이라 나와도 됩니다.

## 내보내기 · 업로드 · 확인

| 단계 | 할 일 |
| --- | --- |
| 형식 | MP4 (H.264 + AAC), 1080p. 파일명 예: `블록체인개론_체인팀_AgentAdTrust_시연영상.mp4` |
| 용량 줄이기 (메일 첨부 한도를 넘을 때) | 아래 명령으로 다시 인코딩하거나 링크로 제출 |
| 업로드 | YouTube ‘일부 공개’ 또는 Google Drive ‘링크가 있는 모든 사용자 · 뷰어’ |
| 접근 확인 | 로그인하지 않은 시크릿 창(또는 다른 계정)에서 링크가 재생되는지 확인 — 가이드 제출 체크 02 |
| 기록 | 이 문서 맨 위 표와 [제출 목록](README.md)에 링크·길이 기입 |

```powershell
ffmpeg -i 원본.mp4 -c:v libx264 -crf 28 -preset medium -c:a aac -b:a 128k 블록체인개론_체인팀_AgentAdTrust_시연영상.mp4
```
