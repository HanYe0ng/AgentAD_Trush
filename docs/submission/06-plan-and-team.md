## 4. 향후 계획

| 현재 한계 | 다음 단계 |
| --- | --- |
| 자체 쇼핑 AI·화면이 보낸 기록을 사용 → 보고 *이전* 조작은 해시로 못 막음 | 매체에 심는 **독립 측정 SDK**(서명된 표시 이벤트), 측정 주체를 매체와 분리 |
| 검증 엔진이 같은 서버에서 실행 | 검증기관 별도 배포, 결과 해시는 지금처럼 체인에 남기고 누구나 재계산 |
| 보류(INCONCLUSIVE) 건의 증빙 보완 절차 없음 | 보류 건 추가 증빙 제출 → 재검증 흐름 |
| 로컬 체인 | Sepolia 배포·Verified → 운영 시 수수료가 낮은 L2 검토 |
| 실제 광고비 결제 없음 | 확정 실적 기준 정산(에스크로) 연동 |
| 단일 검증기관, 관리자가 역할 부여 | 복수 검증기관 합의, 역할 부여 권한 분산 |
| `AD_PRESENTED`는 렌더링 사실이지 사람이 읽었다는 증거가 아님 | 가시성(50%·1초) 등 보조 지표를 계약 조건으로 선택 가능하게 |
