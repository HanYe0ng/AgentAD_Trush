## 작업 내용
홈, 광고주, 소비자, 검증기관, 블록체인 관리 화면의 초기 시안을 제작했다.
사용자 흐름도, 주요 버튼의 동작과 상태, 디자인 시스템을 함께 정리했다.

## 최종 UI 설계

- [최종 Figma 디자인 · 주요 화면 6개](https://www.figma.com/design/uSVPrv9zkHvPKRlyL5LMw2?node-id=7-3)
- [클릭 가능한 최종 프로토타입 · 홈에서 시작](https://www.figma.com/proto/uSVPrv9zkHvPKRlyL5LMw2?node-id=7-3&starting-point-node-id=7%3A3)

초기 시안 5종을 바탕으로 실제 MVP의 역할과 업무 흐름에 맞춰
홈, 광고주, 광고 매체, 소비자, 검증기관, 블록체인 기록의 6개 화면을 구성했다.

- 광고 매체가 계약 조건을 수락하고 광고 실적을 보고하는 흐름을 추가했다.
- 광고주 화면에서 검증 결과를 확인한 뒤 최종 승인하거나 이의를 제기할 수 있도록 했다.
- 검증기관 화면에서 인정·제외·보류 건수와 각 판정의 근거를 확인할 수 있도록 했다.
- 최종 화면에 맞춰 사용자 흐름도, 버튼별 동작 설명, 디자인 시스템을 정리했다.
