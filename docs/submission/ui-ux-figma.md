## 작업 내용
홈, 광고주, 소비자, 검증기관, 블록체인 관리 화면의 초기 시안을 제작했다.
사용자 흐름도, 주요 버튼의 동작과 상태, 디자인 시스템을 함께 정리했다.

## 구현 화면과의 차이 및 보완 항목
현재 MVP는 광고 매체를 포함한 6개 화면으로 구성된다.
광고 매체의 계약 수락과 실적 보고, 광고주의 최종 승인·이의 제기,
검증기관의 인정·제외·보류 판정을 최종 시안에 반영할 예정이다.
